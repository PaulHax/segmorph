DICOM RTSTRUCT and SEG, decoded into one scene

Everything below went through real DICOM bytes: contour stacks are written and re-read as an RT Structure Set (dcmjs), then stitched into closed meshes with contourToSurface - including a ring stored with the RTSTRUCT keyhole technique. Binary masks travel as a multi-frame DICOM SEG whose two segments deliberately overlap (each segment owns its frames), then surface via labelmapToSurface. The adapters live in this example; the segmorph core never sees DICOM.
